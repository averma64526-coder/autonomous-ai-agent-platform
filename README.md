# 🤖 Autonomous AI Agent Platform

A platform where users describe a goal, and AI breaks it into tasks, executes approved actions, checks the results, and reports progress.

## ✨ Features

- Multi-agent collaboration (Planner, Executor, Verifier, Critic)
- Long-term memory (PostgreSQL + vector store)
- Tool integration with sandbox execution
- Human approval for sensitive actions
- Task execution monitoring
- Error recovery and result verification
- Web-based dashboard

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL, Redis
- **LLM:** OpenAI / Anthropic API
- **Infra:** Docker, Nginx
